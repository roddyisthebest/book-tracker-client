# BookTracker 서비스 이용약관

BookTracker를 이용해 주셔서 감사합니다.
본 약관은 BookTracker 앱을 이용할 때 필요한 기본적인 안내 사항을 정리한 문서입니다.

## 제1조 서비스의 목적

BookTracker는 사용자가 자신의 독서 활동을 기록하고 관리할 수 있도록 돕는 앱입니다.

사용자는 BookTracker를 통해 책을 검색하고, 내 서재에 등록하며, 읽는 중인 책, 읽고 싶은 책, 완독한 책, 중단한 책을 관리할 수 있습니다.

또한 구매 또는 대여 영수증을 기록하고, 컬렉션과 독서 통계를 통해 자신의 독서 흐름을 확인할 수 있습니다.

## 제2조 계정 및 로그인

BookTracker는 Apple, Google 또는 이메일 로그인을 통해 이용할 수 있습니다.

사용자는 본인의 계정 정보를 안전하게 관리해야 하며, 타인의 계정을 무단으로 사용해서는 안 됩니다.

로그아웃하더라도 서버에 저장된 데이터는 삭제되지 않으며, 다시 로그인하면 기존 데이터를 계속 이용할 수 있습니다.

## 제3조 사용자 데이터

사용자가 BookTracker에 등록한 책, 컬렉션, 영수증, 독서 기록, 프로필 정보 등은 서비스 제공을 위해 저장될 수 있습니다.

사용자는 앱에서 제공하는 기능을 통해 자신의 데이터를 수정하거나 삭제할 수 있습니다.

사용자가 입력한 정보의 정확성은 사용자 본인에게 책임이 있습니다.

## 제4조 로컬 데이터와 서버 데이터

BookTracker는 서비스 제공을 위해 일부 데이터를 사용자 기기 내부에 저장할 수 있습니다.

최근 검색어, 임시 영수증 데이터 등은 기기에 저장될 수 있으며, 앱 내 데이터 삭제 기능을 통해 삭제할 수 있습니다.

계정과 연결된 책, 컬렉션, 영수증, 독서 기록 등은 서버에 저장될 수 있습니다.

## 제5조 영수증 및 컬렉션 기능

BookTracker의 영수증 기능은 사용자가 구매하거나 대여한 책을 기록하기 위한 기능입니다.

구매 영수증을 발급하면 해당 도서는 구매한 책 컬렉션에 자동으로 추가될 수 있으며, 대여 영수증을 발급하면 대여한 책 컬렉션에 자동으로 추가될 수 있습니다.

자동으로 생성되는 구매/대여 컬렉션은 앱에서 관리하는 시스템 컬렉션으로, 이름이나 설명을 직접 수정할 수 없습니다.

## 제6조 통계 및 기록

BookTracker는 사용자가 입력한 독서 기록, 완독 정보, 영수증 정보 등을 바탕으로 통계와 캘린더를 제공합니다.

통계는 사용자가 입력한 데이터를 기준으로 계산되며, 입력된 정보가 정확하지 않을 경우 통계 결과도 실제와 다를 수 있습니다.

캘린더와 리포트 이미지는 사용자가 직접 저장하거나 공유할 수 있습니다.

## 제7조 데이터 삭제 및 회원 탈퇴

사용자는 앱에서 제공하는 기능을 통해 로컬 데이터 또는 서버 데이터를 삭제할 수 있습니다.

회원 탈퇴를 진행하면 계정과 연결된 서버 데이터는 삭제되며, 삭제된 데이터는 복구할 수 없습니다.

다만, 관련 법령 또는 서비스 운영상 필요한 경우 일부 정보는 일정 기간 보관될 수 있습니다.

## 제8조 사용자의 주의사항

사용자는 BookTracker를 정상적인 목적에 맞게 이용해야 합니다.

다음과 같은 행위는 허용되지 않습니다.

1. 타인의 계정 또는 정보를 무단으로 사용하는 행위
2. 허위 정보를 입력하거나 부정한 목적으로 서비스를 이용하는 행위
3. 앱 또는 서버의 정상적인 동작을 방해하는 행위
4. 비정상적인 방식으로 서버, 데이터베이스, API에 접근하는 행위
5. 관련 법령을 위반하는 행위

## 제9조 외부 서비스 이용

BookTracker는 로그인, 데이터 저장, 도서 검색, 서버 기능 제공 등을 위해 외부 서비스를 사용할 수 있습니다.

외부 서비스의 장애, 정책 변경, API 응답 변경 등으로 인해 일부 기능이 일시적으로 제한되거나 변경될 수 있습니다.

## 제10조 서비스 변경 및 중단

개발자는 앱 개선, 오류 수정, 보안 강화, 서버 점검 등을 위해 서비스의 일부 또는 전체 기능을 변경하거나 일시적으로 중단할 수 있습니다.

중요한 변경 사항이 있는 경우 앱 내 화면 또는 별도 공지 수단을 통해 안내할 수 있습니다.

## 제11조 책임의 제한

BookTracker는 사용자의 독서 기록과 도서 관리를 돕기 위한 도구입니다.

개발자는 사용자가 입력한 정보의 정확성, 데이터 활용 결과, 개인적인 독서 계획의 성과를 보장하지 않습니다.

또한 사용자의 기기 환경, 네트워크 상태, 외부 서비스 장애, 사용자의 데이터 입력 오류 등으로 발생한 문제에 대해 책임을 지지 않습니다.

다만, 관련 법령에 따라 개발자의 책임이 인정되는 경우에는 예외로 합니다.

## 제12조 약관의 변경

개발자는 필요한 경우 본 약관을 변경할 수 있습니다.

변경된 약관은 앱 내 화면 또는 별도 공지 수단을 통해 안내할 수 있으며, 변경 후에도 서비스를 계속 이용하는 경우 변경된 약관에 동의한 것으로 봅니다.
